# Contributing to CallBridge

First off, thank you for considering contributing to CallBridge! It's people like you that make open-source software such a great community to learn, inspire, and create.

CallBridge is part of the **[Vib Tools](https://vib.tools/)** ecosystem. We build **practical software for real workflows** and we expect contributions to align with our core engineering principles:

- **Useful & Focused**: Solve real problems without unnecessary complexity.
- **Maintainable**: Keep the codebase clean, tested, and readable.
- **Developer-Friendly**: Make it easy for others to understand and extend your work.

## How to Contribute

### 1. Find an Issue
Before you start working on a feature or a bug fix, please check the [Issue Tracker](../../issues) to see if someone is already working on it or if it has been discussed. If there isn't an issue for your proposed change, please open one first. This helps us ensure that your work aligns with the project's roadmap and avoids duplicated effort.

### 2. Fork and Clone
Fork the repository to your own GitHub account, and then clone it to your local machine.

### 3. Branching
Create a branch for your feature or bug fix:
```bash
git checkout -b feature/your-feature-name
```
or
```bash
git checkout -b fix/your-bug-fix-name
```

### 4. Development & Testing
- Write clear, concise, and tested code.
- Follow the existing code style and structure.
- Run local tests to ensure you haven't broken any existing functionality.
- For UI changes, test thoroughly across different breakpoints to ensure responsiveness.

### 5. Committing
Keep your commits focused and provide clear commit messages.
```bash
git commit -m "feat: add user authentication via OAuth"
```
```bash
git commit -m "fix: resolve navigation delay on mobile"
```

### 6. Submit a Pull Request
Push your branch to your fork and submit a Pull Request (PR) against the `main` branch of the CallBridge repository. 
- Explain exactly what problem your PR solves.
- Link the related issue(s).
- Provide steps to test your changes.

## Reporting Bugs

If you find a bug, please open an issue and include:
- A clear and descriptive title.
- Steps to reproduce the issue.
- Expected behavior vs. actual behavior.
- Screenshots if applicable.
- Your browser, OS, and any other relevant environment details.

## Security Vulnerabilities
**Do NOT report security vulnerabilities on the public issue tracker.** Please refer to our [Security Policy](SECURITY.md) for instructions on how to safely report security issues to Vib Tools.

## Questions & Support
If you have questions about contributing or need help, please contact us at **[support@vib.tools](mailto:support@vib.tools)**.

Thank you for contributing to CallBridge and the Vib Tools open-source community!
