# Cloud PBX Phone 0.2.2

This release cleans the operational interface while preserving the existing PBX UI structure and theme system.

- Removed descriptive page, panel, and KPI subcopy.
- Added Call History CSV report download.
- Improved recording availability visibility in Call History.
- Added notification and Live/Incoming navigation counts.
- Standardized caller presentation to US `+1` fictional phone numbers.
- Preserved existing dark/light theme tokens, call-state behavior, dependencies, and brand assets.
