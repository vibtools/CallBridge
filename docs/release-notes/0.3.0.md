# 0.3.0 — Autonomous Call Lifecycle

Cloud PBX Phone now maintains a continuously changing browser-local call environment without requiring manual call creation.

## Changes

- New inbound calls arrive on randomized 3–5 minute intervals.
- Ringing inbound calls resolve within 60 seconds: some are automatically answered and the remainder become missed calls.
- Automatically answered calls are distributed across different existing agents/extensions.
- Connected/held calls automatically complete after balanced randomized durations from 2 minutes to 2 hours.
- Newly generated inbound calls use unique fictional US caller numbers.
- Ringing inbound calls use a browser-local ringtone cadence after audio has been enabled by a normal user interaction.
- Completed and missed calls continue to flow through the existing Call History / CDR data view.

The v0.2.1 visual design, themes, layout, branding, dependencies, navigation, and manual call controls are unchanged.
