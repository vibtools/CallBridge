# 0.2.1 — Light Theme Compact PBX Polish

- The light theme now uses a cooler cloud-console canvas, sidebar, topbar, border, and text hierarchy.
- PBX operational states are easier to scan: ringing uses telecom blue, waiting/hold uses amber, connected/available uses green, and missed/failed uses red.
- Overview KPI icons use restrained semantic accents while cards remain neutral.
- Live call rows gain light-theme-only status rails, incoming-call cards gain a clearer signal accent, and queue pressure/progress/chart/waveform colors are more telephony-oriented.
- Keyboard focus visibility is improved in light mode.
- Dark theme, layout dimensions, responsive behavior, mock PBX logic, CDR behavior, dependencies, and brand asset paths are unchanged.
